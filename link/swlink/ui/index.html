Key mapping

triggerverbmodifierskeyface
Trigger: button gestures (single / double / triple click, hold, raw down / up) or IMU gestures (shake, tap, tilt, face down/up). Action: each modifier is off / any side / L / R (right-side keys are distinct to the OS: e.g. right-cmd can be a dedicated hotkey); pick a key; tap presses and releases once; hold while pressed (on a .hold trigger) keeps the key down from the moment the button counts as held until you let go, auto-repeating like a real key; press / release are the manual halves. Click counting is arbitrated on the watch: it waits out the multi-click window, so a double click fires only .double and never .single, and a held button produces no click at all. Raw .down/.up bypass that arbitration and fire on every press — use them only when you want that. ▶ fires the action on this Mac right now and the keystroke lands in the test box. Synthetic keys always go to the frontmost app: when using the watch, bring the app you want to control to the front first.

Kiro face

0 = until changed
The watch shows the Kiro ghost: idle while a host is connected, asleep otherwise. Each mapping row can bind a face (column "face") that flashes for 1.5 s on taps, or is held while a .down button is pressed. A face without a key is fine too — e.g. shake the watch → error face. Apps can drive it with {"t":"mood.set","mood":"working","ms":0}.

Network · Wi-Fi and pairing

Wi-Fi–Device LAN–Pairing–
Credentials go only over the current encrypted/local device link and are stored in the watch NVS; the dashboard and daemon never save or show the password. After connection the daemon finds the watch automatically over mDNS and opens its authenticated TCP link when USB is unplugged.

Power policy and device management

Screen–USB host–History store–
0 disables a timer. Screen-off keeps USB/Wi‑Fi/BLE communication alive. Deep light sleep is used only when USB, Wi‑Fi and BLE are all inactive; a button or timer wakes it. Thus a paired Bluetooth keyboard remains reachable rather than disappearing to save power.

Battery history

Power samples are stored locally once per minute while the daemon is connected. Discharge estimates appear after enough history accumulates.

Bluetooth keyboard (watch as a real HID keyboard)

Watch BLE– Mappings on watch–
1) Enable Bluetooth on the watch (over USB). 2) In macOS Bluetooth settings the watch appears as cfu-watch — click Connect; it pairs as a keyboard, no passkey. 3) From then on button mappings are executed by the watch itself as real HID key events (input methods, games and Karabiner all see them), and the OS handles key auto-repeat. Media keys work too. IMU gestures still need the daemon. Disabling takes effect after the watch reboots.

Virtual microphone (watch mic as a Mac input device)

Pick a loopback device (BlackHole), press Start, then choose that device as the microphone in Zoom / QuickTime / any app. If no BlackHole appears: brew install --cask blackhole-2ch, then sudo killall coreaudiod.
